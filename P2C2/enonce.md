# P2C2 — Deux questions de Claire pour Genie

Claire a vu Genie répondre en quelques secondes, et sa question est arrivée aussitôt :

> « Est-ce que je peux l'utiliser sans passer par vous ? »

Avant de lui répondre, vous voulez voir comment l'agent se comporte sur deux questions qu'elle se pose vraiment. La première est précise. La seconde, elle l'a lancée à l'oral, en fin de réunion, telle quelle.

## Les deux questions

À poser mot pour mot dans votre agent « Fréquence engagement », chacune dans une nouvelle conversation :

**Question 1**

> quelle part des écoutes premium se fait sur mobile ce trimestre ?

**Question 2**

> quels sont nos meilleurs abonnés ?

Ne les reformulez pas avant de les poser : c'est la question brute de Claire que vous testez, pas la vôtre.

## Ce que vous faites pour chacune

1. Posez la question en mode **Chat**, et attendez la réponse.
2. Ouvrez le SQL généré (**Show code** sous la réponse).
3. Copiez-le dans la [grille de lecture](grille-lecture-sql.md) et annotez-le sur les trois points.
4. Rendez un verdict : **exploitable**, **exploitable après correction de l'agent**, ou **à réécrire en SQL**.

Pour la seconde question, notez aussi quelle définition de « meilleurs » Genie a retenue, et si sa réponse le dit.

## Rappel

Ce trimestre, pour Fréquence, c'est le dernier trimestre présent dans les données : juillet, août et septembre 2026. Si votre agent a l'instruction sur la date de référence vue dans le chapitre, Genie devrait le savoir aussi. Vérifiez qu'il l'a appliquée.

## Ce que vous rendez

| Pour chaque question | Format |
|---|---|
| Le SQL généré, annoté sur les trois points | La grille remplie |
| Le verdict | Trois phrases |
| Ce qu'il faudrait préciser, à Genie ou à Claire (question 2 surtout) | Une ou deux phrases |

Les réponses de Genie peuvent varier d'une exécution à l'autre. Ce n'est pas un problème pour l'exercice : vous évaluez la réponse que vous avez obtenue, pas celle d'un autre.
